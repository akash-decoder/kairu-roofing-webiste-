# Kairu Roofing website

Static HTML, CSS, and JavaScript site. `index.html` is the entry point and the `assets/` directory contains the supplied roofing photos.

## Deploy on Vercel

Import this repository in Vercel and use the repository root as the project root. No build command is required. Before deployment, replace `hello@kairuroofing.example` in `index.html` with Kairu Roofing's real email address.

This commit adds the site source to GitHub; it does not deploy the website.
